# 🌐 Web Portfolio | Textile meets Tech

Sitio web portfolio interactivo diseñado y desarrollado desde cero para mostrar la convergencia entre el **diseño textil/industrial** y el **desarrollo de sistemas**.

---

### ✨ Características
- **Enfoque Interdisciplinario:** Presentación de proyectos que fusionan la lógica del diseño técnico textil con soluciones tecnológicas.
- **Diseño Responsive:** Adaptado a diferentes dispositivos mediante maquetación limpia y moderna.
- **Interacciones Dinámicas:** Funcionalidades desarrolladas en JavaScript puro para una experiencia fluida.

---

### 💻 Tecnologías Utilizadas
* **Front-end:** `HTML5`, `CSS3`, `JavaScript (ES6+)`
* **Herramientas de Control de Versiones:** `Git`, `GitHub`
